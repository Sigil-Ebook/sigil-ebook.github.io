Sigil 2.8.6 is a bugfix release.

Sigil 2.8.5 has a bug that can cause damage to the EPUB's opf file if you try to change the cover image of an Epub3. It is recommended that you update to 2.8.6 to avoid this issue.

<div markdown="1">
### Bug Fixes
- fix incorrect Aria Clips icon in the Fluent Theme (Thankyou BeckyEbook)
- fix bug in python plugin wrapper.py that caused application/javascript and application/pls+xml files to be returned as bytes (utf-8) instead of normal python strings (Thank you BeckyEbook)
- fix bug in PluginRunner and python wrapper.py in handling oebps-page-map+xml and application/vnd.adobe-page-map.xml (Thank you BeckyEbook)
- remove duplicate entry for Recording Engineer in MarcRelators list (Thank you BeckyEbook)
- fix endnote backlink in Aria Clips and remove deprecated epub:type endnote use (Thank you BeckyEbook)
- fix bug in epub3 when updating or changing the cover image that can cause OPF manifest entry damage (Thank you ABeater)
</div>
