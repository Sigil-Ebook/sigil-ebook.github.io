Do not use this release. Update to 2.8.6 instead.

<div markdown="1">
### New Features
- remove outdated CSS parser and replace it with a modern spec-compliant Lexbor based css parser. See https://github.com/lexbor/lexbor. Note: Required upstream changes have been approved but are waiting to be merged until other changes requiring a major update are needed (ie size of parser and tokenizer structures needed to grow breaking the ABI).  So do *NOT* replace our internal version of lexbor with a released lexbor version as it will currently not work. We will keep it internal with our own patches and statically linked to prevent dll issues until those requested changes are properly upstreamed.
- improve bulk addition speed of AddExisting/Drop Zone when replacing already existing images by directly using file write with truncation and thereby never touching the opf
- speed up Bookbrowser Refresh by bulk adding and removal items. (contributed by rinne1998)
- try to allow Sigil dock recent items on  macOS platform
- allow multiple selection in the TOC Editor to speed larger changes.
- add image initial size to Sigil's Image tab.
- add ability to create your own Insert Special Characters dialog using special_characters.xml in Sigil prefs folder.  Design and Code credit goes completely to BeckyEbook.
- Completely redesign AdjustImage Cropping to make it more usable. Thanks to byword77
- make Sigil meta use epub version specific tags for Epub 3.4 spec changes
- make svg cover images add href alongside xlink:href for Epub 3.4 spec changes
- make epub3 not add or use old epub2 cover metadata for Epub 3.4 spec changes
- allow epub3 Tools to control creation and removal of cover metadata to ease backwards compatibility
- add support for qt image formats plugins to support avif and jxl images
- add support for polyfilling jxl images in Preview using the URLSchemeHandler and jpeg format
</div>
{: .notice--success}

<div markdown="1">
### Bug Fixes
- move all singleton C++ classes to use the Meyers form to fix leaks, bugs, and speed startup
- prevent leak in Python redirect (contributed by rinne1998)
- fix BookBrowser drag and drop errors with non-contiguous selections.
- remove use of deprecated cmake features in build process
- add code for future support of image/jxf and image/avif formats per epub3.4 spec but neither is directly supported by Qt or QtWebEngine (yet).
- group all duplicate manifest entry warnings into a single epub load warning.
- fix image editor undo history on resize dialog (contributed by rinne1998)
- fix missing translations for the Image Resize dialog (contributed by BeckyDTP)
- make sure css templates content survives other imports
- avoid unchanged search resource rewrites to prevent undo history being lost (contributed by rinne1998)
- fix crash in AppImage when secure links and or remote resources with secure links were present.
- detect malformed OPFs on initial epub load and warn user before auto repairing it
- fix bug in AdjustImage for handling gif Images that Qt can not write using python PIL to create them
- fix numerous user nits in the AdjustImage/Image Tab and make it safer for image types that are read only
- fix crash when adding a font and referencing it before its obfuscation type is set
- use QImageReader and QImageWriter supportedImageFormats to prevent AdjustImage bugs
</div>
{: .notice--success}

__Notes:__

The Sigil Linux AppImage is built on Ubuntu Jammy (22.04) and is targeting glibc 2.35 and higher. Use ldd --version to see if your system at least has a shot at being able to use the AppImage. Don't forget to make sure the AppImage is executable after downloading. Trouble is not expected but be safe and backup your existing Sigil preferences (if you have any) before trying the AppImage.
